# v1.0 — Первый стабильный релиз (15.10.2026)

Первый официальный релиз макроса UniversalReport.

**Что работает:**
- ✅ АМД — сводная с % АО по каждому ТМ и % от общего
- ✅ Часы — мульти по ТЛ с чистым временем
- ✅ УК — мульти по ТЛ, только ФИО + Итого уникальных
- ✅ Кнопка "скопировать изображение" после таблицы
- ✅ Только один видимый макрос UniversalReport

**Скачать:**
- `github_macro.zip` — полный пакет с README и картинками
- `PERSONAL.XLSB` — кинуть в `%APPDATA%\Microsoft\Excel\XLSTART\`
- `UniversalReport.bas` — импорт через File → Import File

**Установка для чайников — смотри README.md, раздел "3 варианта установки". Рекомендуемый — Вариант 3 через PERSONAL.XLSB.**

**Безопасность:** проверено, персональных данных нет, TL_FILTER_LIST пустая.
